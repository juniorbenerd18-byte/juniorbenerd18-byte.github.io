## 📊 Proyek Portofolio

### 🔹 [Analisis Churn Pelanggan](https://github.com/juniorbenerd18-byte/analisis-churn-pelanggan)
Memprediksi risiko churn pelanggan menggunakan **Logistic Regression** dari data simulasi pelanggan telekomunikasi.

- **Tools:** Python, Pandas, Scikit-learn, Matplotlib
- **Insight utama:** Pelanggan baru (< 6 bulan) dengan riwayat komplain tinggi berisiko churn signifikan lebih besar dibanding pelanggan lama.
- **Rekomendasi:** Prioritaskan program retensi untuk segmen ini dan dorong migrasi dari kontrak bulanan ke tahunan.
